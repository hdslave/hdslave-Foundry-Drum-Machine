# Third-party parts

Foundry's own code is in `src/` (except as noted). The borrowed pieces are:

| Part | Where | Licence |
|---|---|---|
| CLAP headers (Free Audio) | `third_party/clap/` | MIT, text in `third_party/clap/LICENSE` |
| Departure Mono font (Helena Zhang), the screen page's glyphs | `src/ui/font.h` | SIL Open Font License 1.1, text in `licenses/OFL-departure-mono.txt` |
| Melodee plug-in screen extension header | `src/melodee_screen.h` | MIT, text in `licenses/MIT-melodee-screen.txt` (Kerem Kiliç, Ellic Studio) |

The panel art is original work for this plug-in.
